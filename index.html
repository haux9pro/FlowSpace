Everything you need

📝

Rich Text Notes

Full-featured Tiptap editor with headings, tables, task lists, inline formatting, tags, and hierarchical notebooks. All stored in local SQLite.

🎙️

Podcast Manager

Subscribe via RSS, search the Podcast Index, browse episodes, and play with a built-in mini-player. Full description expand and duration parsing.

🎵

Google Drive Music

Stream audio files from your own Google Drive. Organize into playlists and enjoy your personal music library directly in the extension.

☁️

Drive Backup

Automatic SQLite database backup to your private Google Drive app data folder. Restore seamlessly on any device.

📅

Calendar & Tasks

Personal events, to-do lists, memorial and anniversary reminders with Vietnamese Lunar calendar integration.

📊

Dashboard Overview

Bento-grid dashboard with statistics, recent notes, quick actions, system health, and a zen quote card. One-click access to everything.

Built with modern tools

TypeScript Vite Tiptap SQLite (sql.js) Google Drive API Chrome Extensions MV3 Shadow DOM Podcast Index
